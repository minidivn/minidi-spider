# PLAN_Minidi_Web — Static Website

## 🎯 Goal
Build a single-file HTML landing page for **Minidi** — a futuristic Wikipedia-styled knowledge explorer with an **embedded AI Chat Edge** panel, designed to showcase the HyperGraph WikiData engine.

## 📦 Tech Stack
- **Single `index.html`** — zero build step, deployable to GitHub Pages
- **CSS** — glassmorphism, animated gradients, grid/flex layout, custom properties for theming
- **JS** — vanilla ES modules pattern, no framework
- **Transformers.js** (CDN) — for optional browser-side semantic search
- **Font** — Inter from Google Fonts

## 🧱 Layout Structure

```
┌─────────────────────────────────────────────────┐
│  🌌 HEADER (Minidi logo + global search bar)    │
├──────────┬──────────────────────┬───────────────┤
│  SIDEBAR │   MAIN CONTENT       │  AI CHAT      │
│  (nav,   │   (article /         │  EDGE         │

│   links) │                      │               │

├──────────┴──────────────────────┴───────────────┤
│  FOOTER (GitHub link, data stats)               │

```

### Typography
- Headings: `Inter` 700
- Body: `Inter` 400
- Code/mono: `JetBrains Mono`

### Effects
- **Glassmorphism**: backdrop-filter blur on cards/panels
- **Animated gradient**: header hero area
- **Glow pulse**: on interactive elements
- **Smooth transitions**: 300ms ease on all state changes

## 📄 Pages / States (all in one HTML)

1. **Landing / Home** — Hero with animated title, quick search, trending topics grid
2. **Article View** — Wikipedia-style article layout with sidebar TOC
3. **Search Results** — Card grid with relevance badges
4. **AI Chat Edge** — Persistent collapsible side panel with conversation history

## 🔌 AI Chat Edge Features
- Slide-in panel from right side
- Chat input with send button
- Message bubbles (user / assistant)
- Typing indicator animation
- Suggested prompts ("What is Vietnam's history?", "Explain HyperGraph")
- Model selection dropdown placeholder
- LocalStorage conversation persistence

## 🚀 Deployment
- Lives in `docs/index.html`
- Deployed via GitHub Pages
- Auto-refreshes when `minidi-spider` CLI exports new `index.json`
